# PEFT Experiments

`iemocap_peft_lora_dora_parameterized.ipynb` is the parameterized source notebook. Select the configuration explicitly before running:

- P1: LoRA r16
- P2: LoRA r8
- P3: LoRA r32, 74.07 weighted F1 at epoch 3
- P4: DoRA r16

`iemocap_p4_dora_r16_b3.ipynb` is retained as the recorded completed DoRA run. The IEMOCAP B3 main table values come from P1 LoRA r16, not P4 DoRA.
