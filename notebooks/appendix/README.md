# Supplementary Experiments

This folder contains reproduction experiments outside the final report's main LLaMA-2-7B 4-bit QLoRA B0–B3 comparison.

- `llama32_3b_baselines/`: LLaMA-3.2-3B baseline reproduction.
- `phi3_baselines/`: Phi-3-mini full fine-tuning baselines.

These artifacts are retained for reproducibility and appendix context. They are not used as evidence for the main Table VI or Table VII results.
