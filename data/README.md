# Local Data Guidance

Raw IEMOCAP and MELD audio are licensed or externally distributed and are not committed to this repository.

Use these Kaggle processed datasets through their Kaggle links:

- https://www.kaggle.com/datasets/kushalag21/meld-b3
- https://www.kaggle.com/datasets/kushalag21/iemocap-with-snr
- https://www.kaggle.com/datasets/kushalag21/meld-denoised-fixed
- https://www.kaggle.com/datasets/kushalag21/iemocap-denoised-dataset

Keep downloaded archives, extracted datasets, credentials, checkpoints, and model weights outside Git tracking.
